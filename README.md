# echo (Rewriten in Rust)

A Unix-like command-line shell written in **Rust**

`echo` is a lightweight, Unix-inspired CLI designed to provide a simple and familiar command-line experience while exploring systems programming and shell development in Rust.

## Features

- Written entirely in Rust
- Unix-like command-line interface
- Lightweight and fast
- Interactive command execution
- File-system navigation
- Designed to be extensible

> **Note:** This project is under active development. Features and behavior may change.

## Installation

### Prerequisites

Make sure you have [Rust](https://www.rust-lang.org/tools/install) and Cargo installed.

### Build from source

```bash
git clone https://github.com/iqbalhrasel/echo-rs.git
cd echo-rs
cargo build --release
```
